# ALWAN.SYSTEM - Infrastructure Engineer Portfolio

Modern React application showcasing the infrastructure engineering, Linux systems administration, MikroTik networking, and IT automation portfolio of **Alwan Farhan Aziz**.

## Features

- **Interactive CLI Terminal**: Functional terminal supporting commands (`help`, `docker ps`, `monitoring`, `vlan`, `skills`, `whoami`, `projects`, `contact`, `clear`).
- **Core Infrastructure Stack**: Dedicated interactive breakdowns and repositories for:
  - **Networking**: MikroTik RouterOS, Layer 2/3 VLANs, WireGuard & IPSec VPNs, ACLs, and NAT.
  - **Linux Server**: Ubuntu Server, SSH hardening, Docker stacks, Nginx reverse proxy, PostgreSQL, and Redis.
  - **Monitoring**: Observability architectures with Prometheus node-exporter, Grafana dashboards, and time-series throughput auditing.
  - **Automation**: Python ETL, Streamlit dashboards, and PowerShell scheduled operations.
- **Enterprise Deep-Dive Showcases**:
  - Enterprise VLAN Segmentation Architecture (VLAN 10, 20, 30, 40)
  - Docker Infrastructure Deployment
  - 24/7 Real-Time Monitoring Dashboard
- **Production Project Catalog**: Over 25 completed enterprise projects for EssilorLuxottica Group, industrial facilities, and freelance clients with video demos and media lightbox inspection.
- **Verified Certifications**: 14 credential cards including MTCNA, Fortinet NSE 4, Linux Foundation CRA / XSS / IT Spec, Cisco CNA, Python, and SQL.
- **Direct Collaboration**: Integrated WhatsApp and Email communication links, plus consultation modal.
- **Resume Download**: Direct access to `CV.pdf`.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 6
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React & Custom SVG Icons

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
